## 🎯 3 Opções de Título de Playlist

```
A) Aprenda o SERENUS — App de Finanças Pessoais 100% Offline e Grátis
```

> **Recomendado: A**
> - "Aprenda o SERENUS" = verbo de ação (puxa intenção de busca)

> - "100% Offline e Grátis" diferencia de toda concorrência

> **Alternativa: C** (se quiser enfatizar a JORNADA completa "do zero ao avançado")

## ⚙️ Configurações da Playlist no YouTube Studio

Ao criar a playlist, configure assim:

| Campo | Valor |
|---|---|
| **Título** | (escolha A, B ou C acima) |
| **Descrição** | (o bloco acima) |
| **Visibilidade** | Pública |
| **Idioma** | Português (Brasil) |
| **Ordenar vídeos** | Manual (você arruma na ordem 00→16) |
| **Permitir comentários** | Sim |

## 🎨 Thumbnail da Playlist (opcional)

YouTube usa o thumb do PRIMEIRO vídeo por padrão. Se quiser custom:

- Resolução: 1280×720 px
- Sugestão de texto grande:
  ```
  APRENDA O SERENUS
  17 episódios · do zero ao avançado
  ```
- Imagem: dashboard do app + ícones dos 7 bancos suportados
- Cor de fundo: roxo `#6D28D9`

## 🔗 Como compartilhar a playlist

Após criar, pegue o link no formato:
```
https://www.youtube.com/playlist?list=<ID_DA_PLAYLIST>
```

Esse link vai em:
- Descrição de TODOS os 17 vídeos (substituir o placeholder `<URL_PLAYLIST>`)
- README do GitHub do Serenus
- Bio do canal UaiScript
- Posts de redes sociais
- Cards no fim de cada vídeo
