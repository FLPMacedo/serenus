⚠️ AVISO DO WINDOWS DEFENDER (falso positivo)
O instalador pode aparecer como "suspeito" pra alguns antivírus porque ainda não tem certificado de code signing. Pra liberar:
1. No aviso azul, clique em "Mais informações"
2. Clique em "Executar mesmo assim"
3. Se ficou em quarentena: Windows Defender → Histórico de proteção → Permitir

📁 ONDE FICAM SEUS DADOS
Tudo do Serenus fica em: %APPDATA%\Serenus\
• serenus.db — TODOS os seus dados financeiros
• backups\ — backups automáticos pré-atualização
• google_token.json — token do Google Drive (se ativar backup na nuvem)

🔒 IMPORTANTE: ao desinstalar o Serenus, os dados em %APPDATA%\Serenus FICAM preservados (segurança). Pra remover tudo, apague essa pasta manualmente.
