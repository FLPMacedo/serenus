⚠️ AVISO DO WINDOWS DEFENDER
O instalador é falso positivo em alguns antivírus (não tem certificado de code signing ainda). Pra liberar:
1. Clica em "Mais informações" no aviso
2. Clica em "Executar mesmo assim"
3. Se ficou em quarentena: Windows Defender → Histórico de proteção → Permitir

📁 ONDE FICAM SEUS DADOS
Tudo do Serenus fica em: %APPDATA%\Serenus\
• serenus.db — TODOS os seus dados
• backups\ — backups automáticos pré-atualização
