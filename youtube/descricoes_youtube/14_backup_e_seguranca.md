## 📋 INÍCIO DA DESCRIÇÃO

```
💾 BACKUP automático no Serenus: local + Google Drive. Nunca mais perca seus dados financeiros — mesmo se o HD pifar, trocar de computador, ou reinstalar o Windows.

📥 BAIXAR SERENUS (grátis):
https://github.com/FLPMacedo/serenus/releases

⏱️ ÍNDICE:
0:00 Hook
0:20 Onde ficam seus dados (%APPDATA%\Serenus)
0:50 Backup MANUAL local (botão "💾 Criar backup")
1:45 Backup AUTOMÁTICO pré-atualização (toda nova versão)
2:30 Como RESTAURAR um backup
3:15 Google Drive (camada extra na nuvem)
3:45 Senha de acesso (criptografada)
4:00 CTA

🔒 PROTEÇÕES NATIVAS DO SERENUS:
✅ Banco SQLite LOCAL — nenhum dado sai do seu PC
✅ Backup MANUAL com 1 clique (gera arquivo com timestamp)
✅ Backup AUTOMÁTICO antes de cada atualização do app (instalador faz)
✅ Restauração com 1 clique (escolhe backup → confirma)
✅ Suporte a Google Drive (opcional, autoriza uma vez)
✅ Senha de acesso ao app (criptografada, não armazenada em texto puro)
✅ Desinstalação PRESERVA os dados em %APPDATA%\Serenus

📁 ESTRUTURA DOS DADOS:
%APPDATA%\Serenus\
├── serenus.db                 ← TODOS os seus dados financeiros
├── backups\                   ← backups manuais e pré-update
│   ├── serenus_backup_20260524_103000.db
│   └── serenus_backup_pre-update_2.3.0_20260524.db
├── google_token.json          ← token Google Drive (se ativou)
└── (outros arquivos do app)

🎯 ESTRATÉGIA RECOMENDADA:
• Backup manual 1x por semana se usa diariamente
• Backup automático já cobre cada atualização
• Google Drive como redundância pra casos extremos
• Mantenha pelo menos 3 backups recentes

⚠️ AO RESTAURAR: o backup SOBRESCREVE seu banco atual. Tudo cadastrado DEPOIS do backup vai sumir. Sempre faça novo backup antes de restaurar outro.
```
