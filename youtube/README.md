## Como usar este material

### Antes de gravar um vídeo
1. Abra `youtube/episodios/<numero>_<nome>.md`
2. O roteiro completo está lá: hook, scripts, telas, CTAs
3. Use o `MANUAL_DEMOS.md` (na raiz) pra escolher o perfil demo certo
4. Os screenshots em `docs/screenshots/` mostram cada tela

### Depois de gravar
1. Suba o vídeo no YouTube
2. Abra `youtube/descricoes_youtube/<numero>_<nome>.md`
3. Copie e cole o texto na descrição do vídeo
4. Edite ❌ marcações pendentes (link do vídeo, timestamp ajustado)
5. Use `youtube/redes_sociais/posts_lancamento.md` pra divulgar

## Atualizações deste material

Cada vez que o Serenus ganhar feature nova, atualize:
1. O roteiro do episódio correspondente em `episodios/`
2. A descrição em `descricoes_youtube/`
3. O `MANUAL_DEMOS.md` se for um caso de uso novo

Material gerado pra versão **v2.3.0** do Serenus.
