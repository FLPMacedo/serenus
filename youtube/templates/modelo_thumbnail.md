# Modelo de Thumbnail — UaiScript / Serenus

> Diretrizes visuais. Use Canva, Photoshop, Figma ou qualquer ferramenta
> que você prefira. Resolução: 1280×720 px (16:9).

---

## 🎨 Identidade visual

| Elemento | Especificação |
|---|---|
| **Cor primária** | Roxo `#6D28D9` (mesmo do Nubank/Serenus) |
| **Cor secundária** | Verde `#10B981` (positivo) |
| **Cor de alerta** | Laranja `#EC7000` (atenção) ou vermelho `#EF4444` (urgência) |
| **Fundo padrão** | Branco `#FFFFFF` ou cinza claro `#F8FAFC` |
| **Texto principal** | Preto `#111827` |
| **Fonte recomendada** | Inter Bold ou Montserrat ExtraBold (chamada) |

## 📐 Regras de ouro

1. **Legível no celular** — texto principal deve ter pelo menos 80px de altura
2. **Máximo 5 palavras** no texto grande
3. **Contraste alto** — fundo claro + texto escuro ou vice-versa
4. **Rosto humano funciona** (CTR maior) — mas só se você gravar
   uma reação genuína, não pose forçada
5. **Setas/círculos vermelhos** chamam atenção (sem exagerar)
6. **Evitar fundo escuro** — YouTube redimensiona e bordas viram pretas
7. **Não copiar elemento do thumb anterior** sem variação — algoritmo penaliza

## 🔄 Consistência de série

Pra ajudar o público reconhecer a série, todos os thumbs devem ter:

- Mesma cor de fundo predominante (branco ou roxo)
- Logo pequena do **Serenus** ou **UaiScript** num canto fixo
- Numeração do episódio (cantinho) — opcional mas ajuda binge-watch

## ✅ Checklist final

- [ ] Resolução 1280×720
- [ ] Tamanho < 2 MB
- [ ] Legível em miniatura (teste no celular)
- [ ] Texto claro (não cobre rostos)
- [ ] Sem violação de direitos autorais (música/imagem)
- [ ] Salvar em PNG ou JPG (PNG melhor pra texto)
- [ ] Nome do arquivo: `thumb_NN_titulo.png`

## 🎁 Ferramentas grátis recomendadas

- **Canva** — templates prontos, fácil pra começar
- **Photopea** — Photoshop online grátis
- **Figma** — pra quem já mexe em design
- **GIMP** — alternativa open source
- **Snappa** — focada em thumbs YouTube
